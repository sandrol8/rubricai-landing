Três passos, dentro da correção

Não é uma ferramenta à parte, usada depois. É uma camada de apoio antes da nota.

PASSO 1

Envio

Você envia o trabalho em PDF ou Word. Trabalhos maiores, como monografias e teses, são aceitos normalmente.

PASSO 2

Análise

O texto é lido trecho por trecho. Cada passagem recebe um indicador próprio, em vez de um número único para o documento inteiro.

PASSO 3

Relatório

Você recebe o nível de atenção do documento, a lista de trechos marcados e o motivo de cada marcação. E decide o que fazer.

O que o relatório traz

Informação suficiente para conversar com o aluno — não um veredito para arquivar.

  • ✓ Nível de atenção do documento, em três zonas
  • ✓ Lista de trechos potencialmente problemáticos
  • ✓ Análise de similaridade textual
  • ✓ Indícios de padrões de escrita artificial
  • ✓ Motivo de cada trecho marcado
  • ✓ Aceita TCC, artigo, monografia e tese
  • ✓ Compra avulsa, sem assinatura
  • ✓ Uso complementar à avaliação acadêmica

O que esta ferramenta não é

Esta seção existe porque um indicador mal interpretado pode prejudicar um aluno inocente.

Não é prova

O resultado é probabilístico. Ele indica que um trecho merece atenção, não que houve fraude. Nenhum número, sozinho, sustenta uma acusação.

Não pune

A plataforma não reprova, não bloqueia e não aciona sanção alguma. Ela informa. Qualquer consequência acadêmica nasce de uma decisão humana.

Não substitui o professor

Quem conhece o aluno, o contexto e o histórico do trabalho é o professor. O relatório serve para orientar a leitura dele, e para abrir conversa.

"Não é uma sentença automática. É uma camada inteligente de apoio à decisão acadêmica."
